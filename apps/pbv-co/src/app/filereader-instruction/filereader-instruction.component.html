First time users of this form cannot select a file to load and must create an XML file by completing all the required fields below and clicking the "Save draft XML" button at the bottom of this form.

For subsequent uses of this form, upload the last final XML file, you received from Health Canada, by clicking on the “Choose file” button and selecting the XML file. If you do not have the final XML file, contact client information unit at client.information@hc-sc.gc.ca.

If you partially complete the form and click on the "Save working copy" button at the bottom of the form, it will save a copy on the local workstation for completion at later time. The file will be saved in the .hcsc file format. The working copies (files with extension .hcsc) should never be sent Health Canada and must be finalized prior to sending.

Les nouveaux utilisateurs de ce formulaire ne peuvent pas sélectionner un fichier à charger et doivent créer un fichier XML en remplissant tous les champs obligatoires ci-dessous et en cliquant sur le bouton « Enregistrer le brouillon XML » au bas de ce formulaire.

Pour les utilisations subséquentes de ce formulaire, téléchargez le dernier fichier XML final que vous avez reçu de Santé Canada, en cliquant sur le bouton « Choisir un fichier » et en sélectionnant le fichier XML. Si vous ne disposez pas du fichier XML final, contactez l'unité d'information client à client.information@hc-sc.gc.ca.

Si vous remplissez partiellement le formulaire et cliquez sur le bouton « Enregistrer la copie de travail » au bas du formulaire, il enregistrera une copie sur le poste de travail local pour qu'elle soit complétée ultérieurement. Le fichier sera enregistré au format de fichier .hcsc. Les copies de travail (fichiers avec extension .hcsc) ne doivent jamais être envoyées à Santé Canada et doivent être finalisées avant l'envoi.
